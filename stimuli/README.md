## Replacing a film clip

Film scenes are copyrighted. If you replace a clip, use one of these routes:

1. **FilmStim** (Schaefer et al., 2010, Université catholique de Louvain). This is a validated database of emotion-eliciting excerpts, provided to researchers on request. Ask your supervisor to request access, and cite it.
2. **The lab buys or rents the films** (DVD or digital) and trims the exact scenes for research use only. This is standard practice, but check your university's copyright guidance.

Save the clip as MP4 in `stimuli/videos/` with the same name, then update its `start` / `end` (seconds) in `config/groups.yaml`, or remove them to play the whole file. To trim a scene with [ffmpeg](https://ffmpeg.org) (`winget install ffmpeg`):

```powershell
ffmpeg -ss 00:MM:SS -to 00:MM:SS -i "full_film.mp4" -c:v libx264 -crf 18 -c:a aac -af loudnorm stimuli\videos\amusement.mp4
```

Use the scene boundaries described in Gross & Levenson (1995) or the FilmStim documentation. Write down the exact source and trim times in your methods section.

## Checking

`python run.py check` lists every clip as found or missing. A real session refuses to start if a clip it needs is missing. All clips are now installed, for every group.

To swap the calm footage, put any `.mp4` or `.webm` files in `nature/`; they play in file-name order.
